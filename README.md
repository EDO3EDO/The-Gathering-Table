# 🍽️ The Gathering Table

> A restaurant web application designed to showcase culinary menus, recipe filtering, and a smooth food browsing experience.

---

## 🔗 Quick Links
* **Live Demo:** [View Live on GitHub Pages](https://edo3edo.github.io/The-Gathering-Table/Home)
* **Status:** Finished / Live

---


## 🛠️ Tech Stack
* **Frontend:** Angular, Standalone Components, TypeScript, RxJS
* **Styling & UI:** Bootstrap 5, Font Awesome, Custom CSS
* **API Communication:** Angular HttpClient
* **Deployment:** GitHub Pages

---

## ✨ Key Features
* **Menu & Recipe Browsing:** Dynamic food and menu item listing with clean layouts.
* **Category Filtering:** Smooth filtering options to let users easily find meals by category or type.
* **Detailed View:** Dedicated pages/modals to view recipe ingredients and meal details.
* **Responsive Design:** Fully optimized layout that works great on mobile, tablet, and desktop.

---

## 💡 Technical Challenges & Solutions
1. **Challenge 1 (First-time API Integration & Data Fetching):**
   * *What happened:* This was my very first time dealing with external APIs and fetching data dynamically into an application, which was a bit tricky at first regarding how to handle the asynchronous responses.
   * *How I fixed it:* Learned how to use Angular's `HttpClient` to properly request data from the backend, subscribe to the observables, and display the meals and menus smoothly on the UI.
